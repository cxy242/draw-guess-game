## 使用与数据保护

1. 先在原站点导出完整数据，保留 v6.5.3 原包，再替换应用文件；不要清除浏览器的网站数据或更换站点来源。IndexedDB 的数据归属浏览器的域名、端口和协议。
2. 服务器若使用音乐 Cookie 管理接口或可选的记忆桥接口，设置至少 24 字符的环境变量 `WANWAN_ADMIN_TOKEN`，在相应应用设置中输入相同令牌。没有令牌时这两个管理入口会拒绝请求。记忆桥还依赖原来的 `127.0.0.1:8001` 服务单独运行；本地测试没有该服务，故只能验证其受保护并能返回 502。
3. 定时补回和匿名来信依赖应用页面打开后的检查；关闭页面、系统休眠或浏览器限制后台任务时不会由云端常驻执行。再次打开后会继续处理未完成的计划槽。匿名短信首次约 25 分钟以这次打开页面的实际时间计算。
4. X 记录在浏览器 IndexedDB 中跨重进保留，备份也包含 X；如果用户清除站点数据、浏览器主动清理存储、磁盘损坏或更换设备，仅凭这份前端源码仍无法保证绝对永久。请定期导出备份；真正跨设备、抗清理的永久归档还需要部署持久化后端与恢复策略。

## 剩余验证边界

没有连接真实服务器、真实 AI 供应商、Android 后台或原始用户数据库进行在线验收。两千帖样本验证的是普通文本帖子与首页分页；超大图片、单帖极多评论以及数十万条历史需要在实际设备上做容量压测。事实语义合并目前是有限的精确冲突键与重复内容维护，不声称已经具备完整语义推理。原角色无 ID 且同名同资料的极端情况仍无法凭名字可靠区分，正常角色档案应保留唯一 ID。

需 Node.js、Playwright、Chrome Headless Shell；`CHROME_EXECUTABLE=/absolute/path/to/chrome-headless-shell node tests/regression.cjs`。服务端检查：`python3 tests/server-smoke.py`。回归会在本机 `127.0.0.1:8765` 建立临时页面，使用隔离的测试浏览器；不操作真实用户数据。
